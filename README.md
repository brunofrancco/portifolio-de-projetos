# Bruno Franco — Portfólio de Projetos

Site pessoal de portfólio em Análise de Dados e Engenharia de Dados, publicado com GitHub Pages.

🔗 **Acesse ao vivo:** https://brunofrancco.github.io/portifolio-de-projetos/

## Sobre

Portfólio one-page apresentando minha atuação na interseção entre Análise de Dados e Engenharia de Dados — da ingestão, validação e modelagem dos dados aos indicadores, relatórios e dashboards que orientam o negócio.

## Seções do site

- **Início** — apresentação e chamada para os projetos e contato
- **Sobre** — trajetória e foco atual em Análise de Dados e Engenharia de Dados
- **Habilidades** — stack de Data Analysis (SQL, Python/Pandas/Numpy, indicadores e relatórios automatizados, EDA, testes de hipótese, BI) e de Data Engineering (pipelines de ETL, modelagem dimensional, qualidade de dados, bancos de dados, Git/Docker/CI, cloud)
- **Projetos** — estudos de caso por área:
  - **Data Engineering**
    - [Plataforma de dados de RH (People Analytics)](https://github.com/brunofrancco/people-analytics-data-platform) — pipeline ELT no GCP: API de HRIS, BigQuery, star schema com dbt, Airflow (Cloud Composer), Terraform e LGPD
    - [Analytics Engineering de e-commerce](https://github.com/brunofrancco/ecommerce-analytics-engineering) — extração de API REST, star schema em DuckDB, validações de qualidade e dashboard em Streamlit
    - [Pipeline e data mart de uma seguradora digital](https://github.com/brunofrancco/insurance-data-analytics) — validação de dados com quarentena, ETL para star schema em SQL, indicadores versionados e relatórios automatizados
  - **Data Analysis**
    - [Superstore Sales Analytics](https://github.com/brunofrancco/Analise-Exploratoria-de-Dados-Superstore-Sales-Analytics) — EDA, testes de hipótese, Pareto e segmentação RFM de vendas de varejo, com dashboard interativo
    - [Customer Analytics: qualidade de dados e EDA](https://github.com/brunofrancco/customer-analytics-data-quality-eda) — limpeza, deduplicação (fuzzy matching) e análise estatística de uma base de clientes
    - *Identificação de imóveis para compra e revenda* — análise exploratória em Python para encontrar imóveis abaixo do preço médio e definir preço ideal de revenda
- **Contato** — e-mail e LinkedIn
