- **Sobre** — trajetória e foco atual em Análise de Dados e Engenharia de Dados
- **Habilidades** — stack de Data Analysis (SQL, Python/Pandas/Numpy, indicadores e relatórios automatizados, EDA, testes de hipótese, BI) e de Data Engineering (pipelines de ETL, modelagem dimensional, qualidade de dados, bancos de dados, Git/Docker/CI, cloud)
